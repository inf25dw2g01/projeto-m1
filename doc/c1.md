# Gym Tracker - Desenvolvimento Web II

## Descrição

Ao longo deste trabalho prático de avaliação da unidade curricular de Desenvolvimento Web II, o nosso projeto baseou-se no desenvolvimento de uma API REST, explorando as operações CRUD (Create, Read, Update, Delete), para suportar um Sistema de Gestão de Ginásio (*Gym Tracker*).

A plataforma permite operar de forma segura sobre perfis de atletas (*Users*), gerir os seus planos de treino personalizados (*Workouts*) e consultar uma biblioteca global de atividades físicas (*Exercises*). A arquitetura contempla relações robustas entre os recursos e regras estritas de isolamento de dados por utilizador.

O projeto foi desenvolvido em **Node.js** (framework **Express**), com persistência de dados em **MySQL** gerida através do ORM **Sequelize**, protegido por múltiplas camadas de autenticação (incluindo **OAuth 2.0**) e executado num ambiente **multi-container Docker**.

A API foi construída a partir de um ficheiro `openapi.yaml` utilizando o **OpenAPI Generator**, que produziu automaticamente a estrutura base dos controladores, serviços e router. Esta abordagem *API-first* garante que a implementação está sempre em conformidade com o contrato da API definido. O **OpenApiValidator** do Express valida automaticamente todos os pedidos e respostas contra o schema definido.

A arquitetura baseia-se em três camadas bem separadas:

- **Controllers** — recebem os pedidos HTTP e delegam para os serviços
- **Services** — contêm a lógica de negócio e interagem com a base de dados via Sequelize
- **Models** — definem as entidades e relações (User, Workout, Exercise, WorkoutExercise)

Para garantir portabilidade e facilidade de execução, o projeto utiliza um ambiente **multicontainer Docker**, com containers para:
- API;
- Base de dados;

Com o comando`docker compose -f docker-compose.prod.yaml up --build`, o sistema arranca automaticamente, configurando a base de dados, levantando a API e disponibilizando o serviço na porta definida.
